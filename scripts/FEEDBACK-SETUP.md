# Отзывы → Google Таблица + Telegram

Сайт отправляет отзыв в Google Apps Script. Скрипт записывает его строкой в Google Таблицу
и присылает сообщение в Telegram. Токен бота хранится только в скрипте — на сайте его нет.

## 1. Бот в Telegram (2 мин)

1. Открой в Telegram **@BotFather** → `/newbot`.
2. Имя, например: `Отзывы конференции`. Юзернейм должен заканчиваться на `bot`, например `conf_ribnita_feedback_bot`.
3. BotFather пришлёт **токен** вида `1234567890:AA...`. Никому его не отправляй и не клади в код сайта.
4. Куда приходят отзывы:
   - **себе в личку** — открой своего бота и нажми «Старт»;
   - **в группу организаторов** — добавь бота в группу и напиши в ней `/start@юзернейм_бота`.

## 2. Google Таблица и скрипт (5 мин)

1. Создай Google Таблицу, например «Отзывы конференции 2026».
2. Меню **Расширения → Apps Script**.
3. Удали всё в редакторе и вставь целиком содержимое файла `scripts/feedback-telegram.gs`. Нажми 💾.
4. Слева ⚙️ **Настройки проекта** → внизу **Свойства скрипта** → «Добавить свойство»:
   - `TELEGRAM_TOKEN` = токен из шага 1.

## 3. Узнать id чата (1 мин)

1. Вернись в редактор (слева `< >`). В выпадающем списке функций вверху выбери **findChatId** → **Выполнить**.
2. Google попросит разрешения: «Проверить разрешения» → свой аккаунт → «Дополнительно» → «Перейти в проект (небезопасно)» → «Разрешить». Это нормально — скрипт твой собственный.
3. Внизу в «Журнале выполнения» появится строка `TELEGRAM_CHAT_ID = 123456789` (у группы число начинается с минуса).
4. Добавь в **Свойства скрипта**: `TELEGRAM_CHAT_ID` = это число.

## 4. Запуск (1 мин)

1. Выбери функцию **setup** → **Выполнить** (снова разреши доступ, если спросит).
2. В Telegram должно прийти «✅ Бот отзывов подключён», в таблице — лист «Отзывы» с заголовками.

## 5. Опубликовать как веб-приложение (2 мин)

1. Справа вверху **Начать развёртывание → Новое развёртывание**.
2. ⚙️ Тип → **Веб-приложение**.
3. «Выполнять как» — **Я**. «У кого есть доступ» — **Все**.
4. **Начать развёртывание** → скопируй **URL веб-приложения** (`https://script.google.com/macros/s/.../exec`).
5. Проверка: открой этот URL в браузере — должно быть `{"ok":true,"status":"работает"}`.

## 6. Подключить к сайту (3 мин)

1. **Vercel** → проект → Settings → Environment Variables:
   `NEXT_PUBLIC_FEEDBACK_ENDPOINT` = URL из шага 5 → Save → Deployments → **Redeploy**.
2. Для локального запуска создай в корне проекта файл `.env.local` с той же строкой:
   `NEXT_PUBLIC_FEEDBACK_ENDPOINT=https://script.google.com/macros/s/.../exec`
   и перезапусти `npm run dev`.

## 7. Тест

Открой `https://conf-youth.vercel.app/feedback/?now=2026-10-31T12:00`, отправь тестовый отзыв.
Должно появиться сообщение в Telegram и строка в таблице. Тестовые строки потом удали из таблицы.

## Если что-то пошло не так

- **Изменил код скрипта** — нужно **Начать развёртывание → Управление развёртываниями → ✏️ → Версия: новая → Развернуть**. URL при этом не меняется.
- **Много отзывов сразу** — Telegram пропускает ~20 сообщений в минуту в группу. Лишние помечаются в таблице «в очереди» и досылаются автоматически раз в минуту. В таблице всё сохраняется сразу.
- Колонка **Telegram** в таблице показывает, ушло ли уведомление: «отправлено» / «в очереди».
