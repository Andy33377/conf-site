# Тексты песен

Один файл — одна песня. Имя файла совпадает со `slug` песни в `src/content/conference.ts`.

Вставьте текст как есть:
- части песни разделяйте пустой строкой;
- первая строка части может быть подписью: «Припев:», «Куплет:», «Бридж: x2» и т. п. — на сайте она будет выделена;
- пустой файл — на странице песни будет «Текст песни появится ближе к конференции».

Добавляйте только тексты, на которые у церкви есть права.
