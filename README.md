# «Я знаю, в Кого я уверовал» — сайт конференции

Next.js 16 (App Router) + Tailwind CSS 4, полностью статический экспорт. Mobile-first: основная версия — телефон (QR-код на бейдже).

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # готовый сайт в папке out/
npm start        # посмотреть собранный out/ локально
```

## Где что менять

| Что | Где |
|---|---|
| Все тексты, дата, место, программа, спикеры, мастер-классы, песни, FAQ, контакты | `src/content/conference.ts` |
| Фото | `public/img/*.webp` (сейчас — временные вырезки из макета, замените на оригиналы) |
| Цвета и шрифты | `src/app/globals.css` (блок `@theme`) |
| Домен для превью в мессенджерах | `metadataBase` в `src/app/layout.tsx` |
| Куда уходят заявки | `NEXT_PUBLIC_FORM_ENDPOINT` в `.env.local` (см. `.env.example`; Formspree / Google Apps Script). Без него форма в демо-режиме |

Тексты песен добавляйте в поле `lyrics` (строфы через пустую строку) — только те, на которые у церкви есть права.

## Возможности

- **«Сейчас идёт / Далее»** на главной и подсветка текущего пункта в программе — по часовому поясу Europe/Chisinau. До конференции — обратный отсчёт, после — ссылка на материалы. Проверка: `/?now=2026-10-31T11:15`.
- **«Моя конференция»**: выбранный мастер-класс сохраняется на телефоне и показывается на главной.
- Отдельная страница у каждого мастер-класса и песни — на них можно делать отдельные QR-коды (например, `/masterclasses/media/` на двери аудитории).
- Нижний таб-бар на телефоне, обычное меню на десктопе.
- FAQ на нативном `<details>` — работает без JS. Шрифты с кириллицей раздаются с вашего домена.

## Деплой

Залейте папку `out/` на любой статический хостинг: Vercel, Netlify, Cloudflare Pages или GitHub Pages (для подпапки включите `basePath` в `next.config.ts`).
